# Metodo di lavoro con gli agenti

**Versione 2.0** · 18/11/2026

Metodo operativo per organizzare lavoro su più agenti, **senza sprecare e senza sbagliare**.
Indipendente dal prodotto: nessuna regola presuppone un linguaggio, uno strumento o un dominio.

## I due file

| file | contiene | quando aprirlo |
| ---- | -------- | -------------- |
| **[`METODO.md`](METODO.md)** · ~4.700 token | tabelle decisionali per momento, le 19 regole in una riga, cosa scrivere nel mandato, come unire il lavoro dei figli | **sempre**: basta da solo per operare |
| **[`PROVE.md`](PROVE.md)** · ~12.000 token | le 19 regole per esteso, i casi reali che le hanno prodotte, i difetti ricorrenti, le aree mai verificate, la storia delle versioni | solo in **tre casi**: una regola non ti torna · devi applicarne una delicata e non sai come · lavori in un ambiente diverso |

**Se sei un agente e devi applicare il metodo: leggi `METODO.md` e basta.**

## Perché due file

Il file unico pesava ~15.600 token, di cui **3.500 servivano a operare**: il resto era evidenza —
utile a chi dubita di una regola, inutile a chi la applica. Su un albero da venti agenti erano
oltre 240.000 token spesi a far leggere prove che nessuno dei venti doveva valutare.

Le regole stanno **solo** in `METODO.md`, le prove **solo** in `PROVE.md`. Nessuna duplicazione,
quindi niente da tenere allineato: i due file non possono divergere.

## Da dove viene

Da **54 applicazioni reali** su prodotti diversi, fra luglio e novembre 2026. Ogni regola porta
accanto da quanti casi viene; dove un dato è fragile — pochi casi, una sola osservazione — è
scritto lì, non in fondo.

I rapporti che le hanno prodotte vivono **fuori da questa cartella**, nel repository in cui il
metodo è stato usato: una cartella di rapporti con un indice, ciascuno marcato con cosa ha dato
al metodo. Non sono necessari per applicare il metodo — servono solo a rimettere in discussione
un numero.

**Questa cartella è autosufficiente e si può copiare altrove così com'è:** i tre file rimandano
solo l'uno all'altro, mai all'esterno.

**Tre errori corretti** sono documentati in `PROVE.md` con cosa dicevano prima e perché erano
sbagliati. Servono a ricordare che le misure hanno smentito dei calcoli, e possono smentirne altri.

## Versione

**2.0**, 18/11/2026. La storia completa, con le tre correzioni di sostanza, è in
[`PROVE.md`](PROVE.md#versioni).

La cifra maggiore cambia quando una regola viene aggiunta, tolta o cambia sostanza; la minore
quando si aggiungono prove o si correggono numeri. **I due file portano sempre la stessa
versione**: se divergono, uno dei due non è stato aggiornato.
